# Архитектура «Лектора»

Как устроен конвейер «текст → аудио» и где какие требования реализованы.
Модули полностью заменяемы: каждый этап — отдельный пакет с понятным
интерфейсом (тр. 27).

```
текст / файл          предобработка            лингвистика                просодия                синтез                выход
──────────────►  files → cleaner → ssml →  tokenizer → normalizer →  stress → syntax →     backends (silero/   →  renderer →  mp3/wav
                 (txt/docx/pdf/…)             (числа, аббревиатуры)    segmentation → focus →  chatterbox/sapi)      (+ отчёт)
                                                                      intonation
```

## Конвейер (`lektor/pipeline.py`)

`Pipeline.run(text, title) -> JobResult` — единственная точка входа.
`dry_run(text)` — разметка и отчёт без синтеза. `build_backend()` —
цепочка движков: запрошенный → silero → chatterbox → sapi.

Этапы: `Cleaner` (чистка) → `extract_ssml` (директивы пользователя) →
`split_sentences` → `TextNormalizer` (числа/аббревиатуры) →
`StressAssigner.stress_tokens` (пары «токен → форма с ударением») →
`SyntaxAnalyzer` (дерево зависимостей) → `Segmenter` (синтагмы) →
`FocusFinder` (логическое ударение) → `IntonationPlanner` (контуры) →
`_to_utterances` (реплики с паузами) → `Renderer` (аудио).

## Соответствие 30 пунктам ТЗ

**Ударения.**
v5_cis_base НЕ ставит ударения сам — каждое слово обязано иметь знак «+»
(иначе читается безударной кашей). `stress.py` гарантирует знак каждому
слову с 2+ гласными; цепочка: словарь пользователя → юрсловарь (леммы,
перенос по номеру гласной: `пригов+ор → пригов+ору`, склонение pymorphy3)
→ правила омографов (срабатывают только при точном контекстном совпадении)
→ silero-stress (нейросеть Silero, 4 млн слов, омографы в контексте,
модели внутри pip-пакета — офлайн) → ruaccent (запасная) → правило «ё»
(знак перед последней «ё») → нейтральный вариант омографа (тр. 4, с отчётом)
→ эвристика «первая гласная» (счётчик в отчёт). Односложные служебные слова
знак не получают (выверено на слух в audiobook-ru); «что/как/где/кто/он» —
получают. Клитики «-то/-ка/-таки» склеиваются с основным словом.
(1) Словарь с морфологией: `legal_stress.json` хранит леммы; формы
получаются переносом ударения по номеру гласной (`пригов+ор → пригов+ору`),
склонение — pymorphy3. (2) Просодическое ядро: ударное слово получает
+70 мс паузы перед собой и повышение тона (`emphasize_word` → Silero
`<prosody pitch="high">`). (3) Юридический словарь — пополняемый
(`dictionaries/legal_stress.json`). (4) Омографы — контекстное
разрешение по соседним словам (`homographs.json`), при неоднозначности —
нейтральный вариант + запись в отчёт. (5) Побочное ударение — оставлено
нейронной модели: Silero сам смягчает безударные слоги; в разметке
фиксируется только главное. (6) Редукция — собственное свойство
нейронного TTS (несколько часов естественной речи в обучении); отдельно
не моделировалась, потому что у Silero/Chatterbox она уже есть.
(7) Аббревиатуры: словарь `abbreviations.json` с чтением по буквам или
как слово, неизвестные — по буквам.

**Членение.**
(8) Каждая запятая — вероятностное решение `_decide_comma` по дереву
зависимостей; «Освободи, меня…» — запятая удалена (связь глагол+дополнение).
(9) `TIGHT_RELS` — неприкасаемые группы (obj/iobj/obl/amod/nmod/case/…).
(10) Синтагмы строятся по синтаксису и семантике, пунктуация — только
сигнал. (11) Паузы: межсинтагменные 150–300 мс (MEDIUM), межфразовые
400–600 мс (STRONG), настраиваются коэффициентами. (12) Вводные, обращения,
тесные группы — отдельные правила границ. (13) SSML-подмножество:
`<break>`, `<emphasis>`, `<prosody rate/pitch>`. (14) Перечисления
`(а), (б), 1), 2)` — контур `enum_continue`, равномерные паузы без
интонации завершения.

**Интонация.**
(15) Фокус — семантический, смещён к концу синтагмы, служебные слова
исключены. (16) Веса по частям речи: существительное > глагол, прилагательные
и местоимения — только при контрасте. (17) Конструкции «не X, а Y» —
акцент на контрастирующем слове. (18) 24 контура в `intonation.py`
(завершение, незавершение, вопрос, перечисление, вводность, обращение…).
(19) Завершённость — понижение (`pitch=low`), незавершённость — ровный тон;
вопросы без вопросительного слова (ИК-3) получают подъём тона на последнем
слове — `<prosody pitch="x-high">` (поле `Segment.question_rise`, приём
проверен на слух в audiobook-ru). Пауза после абзаца — 1,6× межфразовой
(границы абзацев отслеживаются по позициям предложений в тексте).
(20) Юридический тон — режим «Лекция»: 140–160 сл/мин, сдержанные
интервалы. (21) Сложные фрагменты (порог 170 знаков) — `rate="slow"`
(Silero; Chatterbox игнорирует — задокументировано).

**Юрспецифика.**
(22) Терминологический словарь произношения — пополняемый. (23) Первая
аббревиатура — полная расшифровка с «далее — …», падеж согласуется с
контекстом. (24) «ст. 159 ч. 2 п. «в»» → «статьи сто пятьдесят девять,
части второй, пункта вэ». (25) Длинные названия НПА — числа и даты
читаются словами без проглатывания, повторные упоминания — кратко;
диапазоны лет — порядковыми в падеже слова «год»
(«в 2010–2015 годах» → «в две тысячи десятом — две тысячи пятнадцатом годах»).
Нормализатор (порядок проходов не менять!): _shorts («в./вв.» — только
строчные: заглавная «В.» = вольты) → _articles («л.» = лист; количественные
после слова-ссылки не склоняются: «на листе пять») → _law_numbers (№149-ФЗ,
дела «№ 2-123/2021» — тире, не «от…до») → _roman (падеж по соседнему слову:
«в XV в.» → «в пятнадцатом веке»; «часть II» → «часть вторая») →
_phones (+7 926 123-45-67 поцифрово) → _digit_groups (коды 123-45-67) →
_ordinals («19-й/2-я/3-е/158-х/в 3-м» → порядковые в нужном падеже;
«3-х комнатная» → «трёхкомнатная») → _ranges (с защитой от цепочек групп) →
_fractions (1/2 → «одна вторая», 3/4 → «три четверти») → _dot_dates
(«12.03.2021» → «двенадцатого марта две тысячи двадцать первого года»;
подразделы «п. 3.5» → «пункт три пять», версии «3.5.1», IP — по группам;
lookahead «точка+цифра», чтобы точка в конце предложения не мешала) →
_dates (+ «г. Москва» → «город …», «ул./д.»; «в 2006 г.» → «в две тысячи
шестом году») →
_amounts (5 млн/2 тыс. с согласованием падежа и числа) → _measures («23 кг»,
«60 км/ч» → «шестьдесят километров в час», «100 м²» → «сто квадратных
метров», «−5 °C» → «минус пять градусов Цельсия», «220 В» → «вольт») →
_money_time_percent → _half_units («0,5 часа» → «полчаса», «0,5 суток» →
«полсуток», «0,5 лет» → «полгода»; дефис перед гласной/«л»: «пол-литра»;
«0,5%» → «полпроцента») → _numbers (длинные номера ≥7 цифр и ИНН/ОГРН —
поцифрово; дробные — с родом следующего существительного: «1,5 минуты» →
«полторы минуты»; дробные склоняются, связка «с половиной» неизменна:
«от 2,5 км» → «от двух с половиной километров»; после винительных
предлогов «через/за/про/в/на/о/под» родительная форма существительного
не считается падежом предложения: «через 5 километров» → «через пять
километров», но «на 5 страницах» → «на пяти страницах») →
_abbreviations. Токенизация: разрывы предложений после
известных сокращений («л. 5», инициалы «И. И.») склеиваются.

Итерация 20: дробные площади/объёмы — «2,5 м²» больше не обрубается до
«два квадратных метра» (_measure_words: decimal_words при дроби,
единица в род. мн.); «двадцать одна целая» — числительное при «целая»
всегда женского рода; CHANGELOG.md — предрелизная сводка всех итераций.

Итерация 19: четверти — «0,25 часа» -> «четверть часа», «0,75 литра»
-> «три четверти литра», «0,25%» -> «четверть процента», «0,25 км» ->
«четверть километра» (в _half_units для полных единиц и в _measures для
сокращённых); формы согласуются с предлогом по таблицам _QUARTER/_THREE_Q
(«около четверти суток», «с четвертью часа», «около трёх четвертей
метра» — род. мн. у pymorphy ненадёжен, таблица надёжнее).

Итерация 18: «то есть» — связка «есть» безударна и раздельно, и через
дефис («есть» фонетически односложно, но содержит две гласные буквы, из-за
чего уходило в многосложную ветку и получало ложный знак); служебная
проверка добавлена и в многосложную ветку _stress_word; README-аудит
(единицы м/с² и км/с, «пол-»-справочник ударений, --version); профиль
нормализации после новых регэкспов — 1,3 мс/предложение (деградации нет);
фаззинг дефисных слов (300 случайных конструкций) — 0 крашей.

Итерация 17: точечные дроби и единицы — «0.5 часа»/«2.5 млн»/«3.5 м»
(с точкой вместо запятой) больше не читаются поцифрово как версии:
chain-регэкс не берёт двухсегментные «0.Y» и отступает перед единицами
и родительным падежом («7.5 вольт» → «семь с половиной вольт»);
латинское слово перед числом — признак версии, а не даты («Python 3.10»
→ «три десять», но «Дело от 2.10» → «второго октября»); «0,5 кг» →
«полкилограмма», «0,5 л» → «пол-литра», «0,5 км/ч» → «полкилометра в
час» (пол-ветка в _measures); новые единицы: км/с, м/с, м/с², м/с³ («9,8
м/с²» → «…метра в секунду в квадрате»); _articles больше не вырезает
«ч» из «км/ч» (граница слова после «/»); cleaner сохраняет надстрочные
²/³ у единиц («м²», «см³», «км²», «м/с²») — раньше они удалялись как
знаки сносок, и «100 м²» терялось до нормализатора.

Итерация 16: деньги — дробная часть рублей всегда копейки с дополнением
разряда («100 000,5 руб.» → «…пятьдесят копеек», а не «пять»); границы
слов в денежном и «тыс/млн»-регэксах («с 1,5 рублями» больше не рвёт
слово, «1,5 тысячи» не обрезается до «тыс»+«ячи»; «тыс.руб.» без
пробела — легальная запись). Ударения: дефисные слова («кто-то»,
«по-прежнему», «во-первых», «пол-литра») больше не уходят в модель
«оголёнными» — _stress_hyphen_word размечает по частям (клитики
«-то/-либо/-нибудь/кое-» безударны, «кто-то» → «кт+ото» со склейкой
дефиса); справочник HALF_WORD_STRESS закрывает системные ошибки
silero-stress на «пол-»-словах («п+олгода» → «полгод+а»,
«п+олл+итра» → «пол-литр+а», «пол+утора» → «полутор+а»). Версия: CLI
--version, штамп в отчёте и в заголовке GUI/самодиагностики.

Итерация 12: ритм перечислений — однородные члены получают
pitch=high (ИК-3), последний элемент читается ровно; однородность
определяется по rel=conj из синтаксического дерева (падежные теги
неоднозначных plural-форм ненадёжны) + ослабление порога серии до
одного элемента, когда причина границы — «однородные члены»
(двучленные списки тоже поднимаются; придаточные и деепричастные —
нет); _homogeneous дополнительно принимает пары nomn/accs
(неодушевлённый винительный совпадает с именительным); отглагольные
предлоги («в течение/порядке/рамках/случае», «по истечении») —
родительный падеж числа в _numbers (набор _GENT_CTX) и многословные
предлоги («в силу», «в порядке», …) — gent для слова-ссылки в
_articles.

Итерация 11: суффикс «г.»/«года» после полной даты поглощается
(«от 21.01.2025 г.» -> «…двадцать пятого года», без второго «года»;
гард: «г.» перед заглавной буквой = город); «с 2020 по 2024 год» —
диапазон годов ординалами (gent + accs, «…по две тысячи двадцать
четвёртый год»); «более/менее/свыше» + число -> родительный падеж;
обозначения «Т-34/Су-27/Ил-76/ФЗ-152» — дефис заменяется пробелом
(до 4 букв, заглавная в начале; «г-н» с маленькой буквы не задет);
«18+» -> «восемнадцать плюс» (гард: «+7 …» телефона не трогается).

Итерация 10: модель silero-stress грузится один раз на процесс —
общий кэш на уровне класса StressAssigner (раньше каждый экземпляр —
проба голоса, «Как будет читаться», озвучка — грузил модель заново по
3,5 с; тесты ускорились в 5 раз); время «в 12 ч. 30 мин.» -> «12:30»
ещё в _shorts, до прохода ссылок (иначе «ч.» съедалось как «часть»);
«в 12 ч.» -> «12:00» только после предлога времени (гард: «ст. 5 ч. 2»
— часть статьи); «согласно/вопреки» -> дательный; адресные сокращения
пос./пер./лит. + «обл.» с согласованием падежа по предыдущему
прилагательному («Московской обл.» -> «Московской области»); «и/или» ->
«и или» без паузы на слэше.

Итерация 9: суммы с копейками («100 000,50 руб.» -> «сто тысяч рублей
пятьдесят копеек», «,00» не озвучивается); человеческие числа с
разделителями («2 500 000») больше не читаются поцифрово как номера
счётов (поцифрово — только 7+ цифр без пробелов или ИНН-контекст);
дефисные сложные слова («3-летний» -> «трёхлетний», «1-комнатная» ->
«однокомнатная», «25-летие» -> «двадцатипятилетие»; числительное в
родительном падеже приклеивается, «одного»->«одно», «ста»->«сто»);
диапазоны в ссылках («ст. 159-161» -> «статье сто пятьдесят девять —
сто шестьдесят один», ранее «Статьи 158-160» читались «от ста
пятидесяти восьми…»); технические единицы: л.с. (не «лист эс»),
об/мин, кВт·ч (любой разделитель), куб. м и м³ (расширение
rx_multi; «кв. м» не задет).

Итерация 8: размеры через «х» («30х40 см» -> «тридцать на сорок»);
диапазоны времени «10:00-13:00» -> «с десяти до тринадцати часов»
(раньше общий проход диапазонов рвал их на части); время с предлогом
склоняется («с 9:00» -> «с девяти часов», «к 12:00» -> «к двенадцати
часам»); адресные ссылки корп/кв/эт (+ guard: «кв. м» — квадратные
метры, а не «квартира м»; «на 3 этаже» -> «на третьем этаже»,
«3 эт.» -> «третий этаж», мн. ч. «этажами» — количественное);
«г-н/г-жа» -> «господин/госпожа»; «№№» -> «номера»; «США» -> «эс шэ а»
(pymorphy знает «США» как слово — добавили в словарь с чтением);
КАПС-слова судебных актов (с гласными, >= 4 букв) получают
emphasize_word — голосовое усиление как в документе; CLI-батч создаёт
один Pipeline на папку (словари грузятся один раз).

Итерация 7: GUI-кнопка «Озвучить папку…» (пакетная озвучка всех
поддерживаемых файлов папки, прогресс «файл i/N», отмена, сводка
«готово X из N»); вопросная интонация проверена тестом на уровне
сегментов (полярный вопрос — вопрос_rise=True, wh-вопрос — False);
ASCII-кавычки "..." -> «ёлочки» (парные, чередованием); «г.г.» -> «гг.»
(частая некорректная форма годов); «P.S.»/«PS» -> «пэ-эс».

Нормализация, итерация 6: 0-й проход _paren_dedupe — дубль числа
в скобках («100 000 (сто тысяч) рублей») пропускается (слова → число
через pymorphy-нормформы, сравнение с цифрами); «±» → «плюс-минус»;
«т.н. X» → согласование рода по следующему слову; «в ред.» → «в
редакции», «с изм. и доп.» → «с изменениями и дополнениями»; «подп.»
в словах-ссылках; подразделы «ст. 20.2» обрабатываются в _articles
(цепочка читается с запятыми: «пункт третий, часть вторая, статья
двадцать два»); диапазоны с процентами («на 10-15%» → «на десять —
пятнадцать процентов», форма «процента/процентов» по последнему числу);
падеж чисел в диапазоне — по предлогу («в/во» — предложный, «на» —
винительный, «к/по» — дательный, «с/от/до» — родительный).

Очистка текста: сначала нормализация вида (BOM, CRLF→LF, невидимые
символы \u200b/\u200c/\u200d/\u00ad, «--» и « - » между словами → «—»,
дефис внутри слова не трогается); маркеры списков — словами («1.» →
«Первое —», «а)» → «Пункт а —», тире-буллеты убираются); настоящий блок
сносок — только строки «1 Слово…» (цифра + пробел) в конце, список
«1. Слово» сноской не считается (раньше списки в конце документов молча
пропадали). Сверхдлинные сегменты (>400 знаков, текст без запятых)
режутся по словам — у движков есть предел длины запроса. Чтение файлов:
+ .html/.htm (BeautifulSoup, инлайн-теги не рвут фразу). CLI: -o теперь
работает (файл или папка), --doctor — самодиагностика (модули, словари,
модель, проба ударений и синтеза). GUI: закрытие во время озвучки
спрашивает подтверждение и мягко останавливает поток.
(26) Чистка шума и режим сносок (`skip` / `end` с приглушением −4 дБ).

**Архитектура.**
(27) Модули выше; движок — интерфейс `Backend`, добавление нового — один
класс. (28) Пользовательский словарь `словари/ударения.txt` (формат
«остр+ота»), подхватывается при каждом запуске; опционален.
(29) Режимы «Лекция» и «Чтение документа» — разные наборы темпа/пауз

аббревиатура, число) — с причиной и контекстом; пример в README.

## Почему такие движки

- **Silero v5_cis_base** (MIT, 48 кГц): единственная качественная
  офлайн-модель с русским SSML и разметкой ударений, 29 голосов, ~130 МБ,
  работает на CPU. Основной.
- **Chatterbox** (MIT): самый естественный открытый русский TTS (2025),
  GPU, клонирование голоса. Дополнительный для качества.
- **SAPI** (встроен в Windows): гарантированный запасной без загрузок.

Облачные SpeechKit/SaluteSpeech отвергнуты сразу: платно и требуют
постоянного интернета.
