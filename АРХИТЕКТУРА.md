# Архитектура «Лектора»

Как устроен конвейер «текст → аудио» и где какие требования реализованы.
Модули полностью заменяемы: каждый этап — отдельный пакет с понятным
интерфейсом (тр. 27).

```
текст / файл          предобработка            лингвистика                просодия                синтез                выход
──────────────►  files → cleaner → ssml →  tokenizer → normalizer →  stress → syntax →     backends (silero/   →  renderer →  mp3/wav
                 (txt/docx/pdf/…)             (числа, аббревиатуры)    segmentation → focus →  chatterbox/sapi)      (+ отчёт)
                                                                      intonation
```

## Конвейер (`lektor/pipeline.py`)

`Pipeline.run(text, title) -> JobResult` — единственная точка входа.
`dry_run(text)` — разметка и отчёт без синтеза. `build_backend()` —
цепочка движков: запрошенный → silero → chatterbox → sapi.

Этапы: `Cleaner` (чистка) → `extract_ssml` (директивы пользователя) →
`split_sentences` → `TextNormalizer` (числа/аббревиатуры) →
`StressAssigner.stress_tokens` (пары «токен → форма с ударением») →
`SyntaxAnalyzer` (дерево зависимостей) → `Segmenter` (синтагмы) →
`FocusFinder` (логическое ударение) → `IntonationPlanner` (контуры) →
`_to_utterances` (реплики с паузами) → `Renderer` (аудио).

## Модули

| Модуль | Ответственность |
|---|---|
| `textproc/files` | чтение .txt/.docx/.pdf/.fb2/.epub/.rtf |
| `textproc/cleaner` | дефисы переносов, колонтитулы, номера страниц, сноски (тр. 26) |
| `textproc/ssml` | подмножество SSML: break/emphasis/prosody; позиции — в очищенном тексте (тр. 13) |
| `lingua/tokenizer` | предложения и слова (razdel) |
| `lingua/normalizer` | числа, даты, деньги, время, статьи/части/пункты, диапазоны, №, аббревиатуры (тр. 23–25) |
| `lingua/morphology` | морфология (pymorphy3 + natasha): падежи, части речи, склонение |
| `lingua/numerals` | числительные словами с родом/падежом/родом согласования |
| `lingua/stress` | расстановка ударений с ГАРАНТИЕЙ полного покрытия (тр. 1–7, 28) |
| `lingua/syntax` | дерево зависимостей (natasha sintax), тесные группы (тр. 9) |
| `lingua/segmentation` | синтагмы, решение по каждой запятой, паузы, перечисления (тр. 8, 10–12, 14) |
| `lingua/focus` | логическое и контрастивное ударение (тр. 15–17) |
| `lingua/intonation` | 24 интонационных контура, классификация предложения (тр. 18–21) |
| `synthesis/backends` | общий интерфейс движка: `Segment`/`Utterance`/`Backend` |
| `synthesis/silero_backend` | Silero v5_cis_base: SSML-разметка, 29 голосов, `+`-ударения |
| `synthesis/chatterbox_backend` | Chatterbox HD (GPU): клонирование голоса по образцу |
| `synthesis/sapi_backend` | голоса Windows через SAPI/pyttsx3 |
| `synthesis/renderer` | сборка аудио: кэш реплик на диск → обрезка тишины → нормализация → темп (WSOLA) → паузы → WAV/потоковый MP3 + авто-чистка кэша (>1,5 ГБ → до 1 ГБ, старые первыми). Полный отказ синтеза = громкая ошибка, файл из одних пауз НЕ создаётся |
| `synthesis/audio` | WAV/MP3, RMS-нормализация, WSOLA time-stretch, ресемплинг |
| `ui/gui` | окно программы (customtkinter): текст, настройки, прогресс, отмена |
| `cli` / `__main__` | командная строка и drag&drop (`Озвучить файл.bat`) |
| `report` | события и человекочитаемый отчёт (тр. 30) |
| `config` | режимы «Лекция»/«Чтение документа», настройки, пути (тр. 29) |

## Соответствие 30 пунктам ТЗ

**Ударения.**
v5_cis_base НЕ ставит ударения сам — каждое слово обязано иметь знак «+»
(иначе читается безударной кашей). `stress.py` гарантирует знак каждому
слову с 2+ гласными; цепочка: словарь пользователя → юрсловарь (леммы,
перенос по номеру гласной: `пригов+ор → пригов+ору`, склонение pymorphy3)
→ правила омографов (срабатывают только при точном контекстном совпадении)
→ silero-stress (нейросеть Silero, 4 млн слов, омографы в контексте,
модели внутри pip-пакета — офлайн) → ruaccent (запасная) → правило «ё»
(знак перед последней «ё») → нейтральный вариант омографа (тр. 4, с отчётом)
→ эвристика «первая гласная» (счётчик в отчёт). Односложные служебные слова
знак не получают (выверено на слух в audiobook-ru); «что/как/где/кто/он» —
получают. Клитики «-то/-ка/-таки» склеиваются с основным словом.
(1) Словарь с морфологией: `legal_stress.json` хранит леммы; формы
получаются переносом ударения по номеру гласной (`пригов+ор → пригов+ору`),
склонение — pymorphy3. (2) Просодическое ядро: ударное слово получает
+70 мс паузы перед собой и повышение тона (`emphasize_word` → Silero
`<prosody pitch="high">`). (3) Юридический словарь — пополняемый
(`dictionaries/legal_stress.json`). (4) Омографы — контекстное
разрешение по соседним словам (`homographs.json`), при неоднозначности —
нейтральный вариант + запись в отчёт. (5) Побочное ударение — оставлено
нейронной модели: Silero сам смягчает безударные слоги; в разметке
фиксируется только главное. (6) Редукция — собственное свойство
нейронного TTS (несколько часов естественной речи в обучении); отдельно
не моделировалась, потому что у Silero/Chatterbox она уже есть.
(7) Аббревиатуры: словарь `abbreviations.json` с чтением по буквам или
как слово, неизвестные — по буквам.

**Членение.**
(8) Каждая запятая — вероятностное решение `_decide_comma` по дереву
зависимостей; «Освободи, меня…» — запятая удалена (связь глагол+дополнение).
(9) `TIGHT_RELS` — неприкасаемые группы (obj/iobj/obl/amod/nmod/case/…).
(10) Синтагмы строятся по синтаксису и семантике, пунктуация — только
сигнал. (11) Паузы: межсинтагменные 150–300 мс (MEDIUM), межфразовые
400–600 мс (STRONG), настраиваются коэффициентами. (12) Вводные, обращения,
тесные группы — отдельные правила границ. (13) SSML-подмножество:
`<break>`, `<emphasis>`, `<prosody rate/pitch>`. (14) Перечисления
`(а), (б), 1), 2)` — контур `enum_continue`, равномерные паузы без
интонации завершения.

**Интонация.**
(15) Фокус — семантический, смещён к концу синтагмы, служебные слова
исключены. (16) Веса по частям речи: существительное > глагол, прилагательные
и местоимения — только при контрасте. (17) Конструкции «не X, а Y» —
акцент на контрастирующем слове. (18) 24 контура в `intonation.py`
(завершение, незавершение, вопрос, перечисление, вводность, обращение…).
(19) Завершённость — понижение (`pitch=low`), незавершённость — ровный тон;
вопросы без вопросительного слова (ИК-3) получают подъём тона на последнем
слове — `<prosody pitch="x-high">` (поле `Segment.question_rise`, приём
проверен на слух в audiobook-ru). Пауза после абзаца — 1,6× межфразовой
(границы абзацев отслеживаются по позициям предложений в тексте).
(20) Юридический тон — режим «Лекция»: 140–160 сл/мин, сдержанные
интервалы. (21) Сложные фрагменты (порог 170 знаков) — `rate="slow"`
(Silero; Chatterbox игнорирует — задокументировано).

**Юрспецифика.**
(22) Терминологический словарь произношения — пополняемый. (23) Первая
аббревиатура — полная расшифровка с «далее — …», падеж согласуется с
контекстом. (24) «ст. 159 ч. 2 п. «в»» → «статьи сто пятьдесят девять,
части второй, пункта вэ». (25) Длинные названия НПА — числа и даты
читаются словами без проглатывания, повторные упоминания — кратко;
диапазоны лет — порядковыми в падеже слова «год»
(«в 2010–2015 годах» → «в две тысячи десятом — две тысячи пятнадцатом годах»).
Нормализатор (порядок проходов не менять!): _shorts («в./вв.» — только
строчные: заглавная «В.» = вольты) → _articles («л.» = лист; количественные
после слова-ссылки не склоняются: «на листе пять») → _law_numbers (№149-ФЗ,
дела «№ 2-123/2021» — тире, не «от…до») → _roman (падеж по соседнему слову:
«в XV в.» → «в пятнадцатом веке»; «часть II» → «часть вторая») →
_phones (+7 926 123-45-67 поцифрово) → _digit_groups (коды 123-45-67) →
_ordinals («19-й/2-я/3-е/158-х/в 3-м» → порядковые в нужном падеже;
«3-х комнатная» → «трёхкомнатная») → _ranges (с защитой от цепочек групп) →
_fractions (1/2 → «одна вторая», 3/4 → «три четверти») → _dates (+ «г.
Москва» → «город …», «ул./д.»; «в 2006 г.» → «в две тысячи шестом году») →
_amounts (5 млн/2 тыс. с согласованием падежа и числа) → _measures («23 кг»,
«60 км/ч» → «шестьдесят километров в час», «100 м²» → «сто квадратных
метров», «−5 °C» → «минус пять градусов Цельсия», «220 В» → «вольт») →
_money_time_percent → _numbers (длинные номера ≥7 цифр и ИНН/ОГРН —
поцифрово) → _abbreviations. Токенизация: разрывы предложений после
известных сокращений («л. 5», инициалы «И. И.») склеиваются.
Очистка текста: маркеры списков — словами («1.» → «Первое —», «а)» →
«Пункт а —», тире-буллеты убираются); настоящий блок сносок — только
строки «1 Слово…» (цифра + пробел) в конце, список «1. Слово» сноской
не считается (раньше списки в конце документов молча пропадали).
(26) Чистка шума и режим сносок (`skip` / `end` с приглушением −4 дБ).

**Архитектура.**
(27) Модули выше; движок — интерфейс `Backend`, добавление нового — один
класс. (28) Пользовательский словарь `словари/ударения.txt` (формат
«остр+ота»), подхватывается при каждом запуске; опционален.
(29) Режимы «Лекция» и «Чтение документа» — разные наборы темпа/пауз
(`config.py`). (30) Лог + отчёт: каждое решение (запятая, омограф,
аббревиатура, число) — с причиной и контекстом; пример в README.

## Почему такие движки

- **Silero v5_cis_base** (MIT, 48 кГц): единственная качественная
  офлайн-модель с русским SSML и разметкой ударений, 29 голосов, ~130 МБ,
  работает на CPU. Основной.
- **Chatterbox** (MIT): самый естественный открытый русский TTS (2025),
  GPU, клонирование голоса. Дополнительный для качества.
- **SAPI** (встроен в Windows): гарантированный запасной без загрузок.

Облачные SpeechKit/SaluteSpeech отвергнуты сразу: платно и требуют
постоянного интернета.

## Тесты

`tests/` — 66 тестов: числительные, нормализация (статьи/даты/деньги/
диапазоны лет/суммы млн-тыс/дроби/телефоны/номера дел/адреса), списки
и сноски в очистке, вопросы ИК-3, паузы абзацев, кэш реплик, потоковый
MP3,
ударения (словари, омографы, односложные), сегментация (вредная запятая,
вводные), сквозной dry-run и рендер со стаб-движком. Запуск:
`.venv\Scripts\python.exe -m pytest tests/ -q` (pytest ставится с
requirements-dev.txt или вручную).
