# Лектор — текст в аудиолекцию (Windows 11, полностью бесплатно и офлайн)

Скинул текст или документ — получил готовую аудиозапись, которую можно
слушать на прогулке. Русские юридические тексты любой длины читаются
как человек: с правильными ударениями, живыми паузами и ровным
«юридическим» тоном.

- **Полностью бесплатно.** Никаких облачных сервисов и подписок.
- **Полностью офлайн** после установки (интернет нужен один раз — на установку).
- **Любая длина текста** — книга на 500 страниц читается так же спокойно, как абзац.
- **Выход — файл** MP3 (или WAV).

---

## Быстрый старт

1. **`install.bat`** — двойной клик. Сам поставит Python (если нет), библиотеки
   и голосовую модель (~1,5–2 ГБ, 5–15 минут). Не выключайте интернет до конца.
   Если установка прервалась — просто запустите `install.bat` ещё раз:
   каждый шаг можно повторять без вреда, установка продолжится с места остановки.
2. **`ЛЕКТОР.bat`** — двойной клик. Откроется окно программы.
3. Вставьте текст (или кнопка «Открыть файл…»: `.txt .docx .pdf .fb2 .epub`),
   выберите голос, нажмите **«Озвучить»**.

Установщик в конце сам прогоняет проверку и сохраняет два файла в
**`Аудиолекции`**: «Проверка установки.wav» и «Проверка полной озвучки.wav»
(вторая — через весь конвейер: ударения, паузы, интонация). Послушайте их:
если фразы звучат чисто и с нормальными ударениями, всё встало правильно.

Готовый файл появится в папке **`Аудиолекции`** рядом с программой вместе с
**отчётом** — что и почему программа исправила в тексте.

Поддерживаются файлы .txt .md .docx .pdf .fb2 .epub .rtf .html (разметка
HTML убирается, заголовки и абзацы сохраняются). Файлы Windows (CRLF, BOM)
и текст, скопированный из интернета (невидимые символы, «--» вместо
тире), приводятся к нормальному виду автоматически.

**Разбивка по главам** — включите «Разбивать по главам (по заголовкам
текста)»: строки без точки в конце, за которыми следует пустая строка,
считаются заголовками — книга собирается в отдельные файлы «Название —
часть 01.mp3, часть 02.mp3…» с ID3-тегами каждой части. Из консоли:
`python -m lektor книга.txt --chapters`. Жёстко свёрстанные PDF (строки
по 60-70 знаков с одиночными переносами) при этом не рассыпаются —
режем только по настоящим абзацам.

**Озвучить папку целиком** — кнопка «Озвучить папку…» озвучивает все
поддерживаемые файлы из выбранной папки по очереди (каждый — отдельное
аудио), с прогрессом «файл 3 из 12» и возможностью отмены. То же самое
из консоли: `python -m lektor папка_с_текстами`.

Полезные кнопки:

- **«Разметка»** — предпросмотр без синтеза: как текст будет прочитан
  (ударения знаком «+», паузы «⟦240 мс⟧») + сразу отчёт;
- **«▶ Прослушать голос»** — короткая проба выбранным голосом;
- во время сборки показывается прогресс и примерное оставшееся время;
- **«Отчёт»** — открыть отчёт последней озвучки.

Повторная сборка того же текста почти мгновенная: готовые реплики
кэшируются в `данные/кэш` (кэш сам чистит старые записи, если вырастет
больше 1,5 ГБ). Окно программы запоминает размер, положение и тему
(тёмная/светлая); недавние файлы — в списке «Недавние»; кнопка
«▶ Прослушать голос» озвучивает пробу с настоящей разметкой ударений.

**Большие тексты**: MP3 пишется потоково, без промежуточного
гигабайтного WAV — озвучка книги на много часов не занимает лишнее
место на диске.

**Командная строка** (`python -m lektor`):

```
python -m lektor лекция.txt                  # один файл -> MP3
python -m lektor папка_с_текстами            # ПАКЕТНО: все файлы папки
python -m lektor закон.pdf -o закон.mp3      # точное имя файла
python -m lektor текст.txt -o Готовое/       # в указанную папку
python -m lektor текст.txt --markup          # только разметка и отчёт
python -m lektor текст.txt --no-cache        # собрать заново, минуя кэш
python -m lektor --doctor                    # самодиагностика установки
```

**Самодиагностика** — двойной клик по `ДИАГНОСТИКА.bat` (или
`python -m lektor --doctor`) проверяет все модули, словари, модель
голоса, расставляет ударения в пробной фразе и — если модель на месте —
синтезирует пробу в `Аудиолекции/Диагностика.wav`. Если что-то не так,
пишет, что именно сделать (какую команду выполнить).

Во время сборки показывается оценка оставшегося времени.

### Ещё быстрее
Перетащите файл с текстом на ярлык **`Озвучить файл.bat`** — аудио соберётся
без открытия окна.

## Голоса

| Движок | Голоса | Когда использовать |
|---|---|---|
| **Silero** | 29 русских голосов (мужские и женские) | По умолчанию. Быстрый, точные ударения, отлично работает на любом процессоре — видеокарта не нужна |
| **Chatterbox HD** | 1 голос + клонирование любого голоса по образцу (10–20 сек аудио) | Самый живой, «как диктор». Быстрый только на NVIDIA; на AMD и процессоре — работает, но собирает аудио в 5–10 раз дольше реального времени (час аудио — часы ожидания). Ставится по желанию: `.venv\Scripts\python.exe -m lektor.download_models --chatterbox` |
| **Голоса Windows** | все голоса, установленные в системе | Запасной вариант, если Silero недоступен |

**Про видеокарты.** Ускорение PyTorch (CUDA) доступно только для NVIDIA. С AMD
(в том числе на 6–12 ГБ) или без видеокарты установщик сам поставит
CPU-вариант — Silero на процессоре синтезирует быстрее реального времени
(минута аудио за несколько секунд), так что для повседневной озвучки
карта вообще не нужна.

Кнопка **«▶ Прослушать голос»** проговаривает пробную фразу выбранным голосом.

## Режимы

- **Лекция** — размеренно, 140–160 слогов в минуту, выразительные паузы,
  сложные фрагменты читаются медленнее. Для прослушивания на ходу.
- **Чтение документа** — быстрее и ровнее, паузы короче. Для сплошных
  документов «как есть».

## Что программа делает с текстом автоматически

- **Ударения**: у КАЖДОГО слова (модель рассчитана на полную разметку).
  Источники по порядку: ваш словарь → юридический словарь (пригово́р,
  протоко́л, экспер́т, дактилоскопи́я, осуждённый, возбуждено́…) → правила
  омографов → нейросеть **silero-stress** (от Silero, 4 млн слов, работает
  офлайн — модели уже внутри пакета, ничего не докачивается) → правило «ё» →
  эвристика. Омографы (за́мок/замо́к, му́ка/мука́, у́же/уже́) решаются по
  контексту; если контекст неоднозначен — нейтральный вариант и запись в отчёт.
  Дефисные слова («кто-то», «по-прежнему», «во-первых») размечаются по
  частям с безударными клитиками, а «пол-»-формы («полчаса», «пол-литра»)
  берутся из встроенного справочника точных ударений.
- **Запятые — по смыслу, а не механически**: «Освободи, меня от уголовной
  ответственности» не разрывается паузой — запятая рвёт глагол и дополнение,
  и программа её игнорирует (все такие решения — в отчёте). Вводные слова,
  обращения, причастные обороты — наоборот, получают внятную паузу.
- **Числа и ссылки**: «ч. 2 ст. 159 УК РФ» → «части второй, статьи сто
  пятьдесят девять УК РФ»; даты («в 2010–2015 годах» → «в две тысячи
  десятом — две тысячи пятнадцатом годах»), суммы, проценты, время —
  словами, с правильным падежом; «в т.ч.», «т.к.», «и др.» — расшифровываются.
- **Интонация вопросов**: «Ты пойдёшь?» читается с подъёмом тона на
  последнем слове (ИК-3), а не как утверждение; после абзацев — пауза
  заметно длиннее, чем между предложениями, как у живого чтеца.
- **Списки**: «1. Законность.» читается «Первое — законность.», «а)» —
  «Пункт а — …», маркеры-тире убираются. Пункты списка больше не
  приклеиваются к предыдущему предложению и не теряются.
- **Суммы и единицы**: «5 млн рублей», «2 тыс.» — с правильным
  согласованием («две тысячи», «с двумя тысячами»), «1,5 млрд руб.» —
  «полтора миллиарда рублей».
- **Адреса и номера**: «г. Москва, ул. Ленина, д. 5» — «город Москва,
  улица Ленина, дом пять»; дело «№ 2-123/2021» — «номер два — сто
  двадцать три — две тысячи двадцать первый»; телефоны («+7 926
  123-45-67») и длинные номера (ИНН) — поцифрово; дроби «1/2» — «одна
  вторая», «3/4» — «три четверти»; диапазоны «2010-2015 гг.» —
  «две тысячи десятого — две тысячи пятнадцатого годов».
- **Порядковые числительные**: «во 2-й половине», «с 19-го раза», «3-х
  комнатная», «на л. 5» — читаются правильными формами («во второй
  половине», «трёхкомнатная», «на листе пять»).
- **Единицы измерения**: «23 кг», «60 км/ч», «100 м²», «12 Гб», «220 В»,
  «−5 °C», «9,8 м/с²», «8 км/с» — словами с согласованием («шестьдесят
  километров в час», «метра в секунду в квадрате», «минус пять градусов
  Цельсия»).
- **Римские цифры**: «в XV в.» — «в пятнадцатом веке», «часть II» —
  «часть вторая».
- **Даты через точку**: «от 12.03.2021» — «от двенадцатого марта две
  тысячи двадцать первого года», «до 01.09» — «до первого сентября»;
  при этом «п. 3.5» — «пункт три пять», «версия 3.5.1» — «три пять
  один» (версии и номера подразделов не путаются с датами).
- **Половины**: «2,5 млн» — «два с половиной миллиона», «12,5%» —
  «двенадцать с половиной процентов»; «0,5 часа» — «полчаса», «0,5
  суток» — «полсуток», «0,5 года» — «полгода», «0,5 литра» —
  «пол-литра», «0,5%» — «полпроцента»; «1,5 минуты» — «полторы
  минуты» (род по существительному); «100 000,5 руб.» — «сто тысяч
  рублей пятьдесят копеек» (дробная часть рублей — всегда копейки
  с дополнением разряда); «от 2,5 километров» — «от двух с половиной
  километров» (дробные склоняются по предлогу, связка «с половиной»
  неизменна); «через 5 километров» — «через пять километров»
  (винительный падеж после «через/за/про», но «на 5 страницах» —
  «на пяти страницах»).
- **Юридические обороты**: «в ред. ФЗ от 01.09.2024 № 152-ФЗ» — «в
  редакции федерального закона … номер сто пятьдесят два фэ-зэ»;
  «(с изм. и доп.)» — «с изменениями и дополнениями»; «подп. „а“
  п. 3 ч. 2 ст. 20.2» — «подпункт а, пункт третий, часть вторая,
  статья двадцать два» (с паузами-запятыми); «на 10-15%» — «на десять —
  пятнадцать процентов»; «±3 мм» — «плюс-минус три миллиметра».
- **Быт и адреса**: «30х40 см» — «тридцать на сорок сантиметров»;
  «10:00-13:00» — «с десяти до тринадцати часов»; «с 9:00» — «с девяти
  часов» (падеж по предлогу); «г-н Иванов» — «господин Иванов»;
  «корп. 2, кв. 17, 3 эт.» — «корпус два, квартира семнадцать, третий
  этаж»; «№№ 1, 2» — «номера один, два»; «США» — «эс шэ а».
- **Деньги и единицы**: «100 000,50 руб.» — «сто тысяч рублей
  пятьдесят копеек»; «3-летний» — «трёхлетний», «25-летие» —
  «двадцатипятилетие»; «ст. 159-161» — «статье сто пятьдесят девять —
  сто шестьдесят один»; «150 л.с.» — «сто пятьдесят лошадиных сил»;
  «3000 об/мин», «250 кВт·ч», «12 куб. м», «25 м³» — всё словами;
  «2 500 000» с разделителями — человеческое число («два миллиона
  пятьсот тысяч»), а ИНН без пробелов — поцифрово.
- **География и время**: «в 12 ч. 30 мин.» — «в двенадцать часов
  тридцать минут» (и «с 10 ч. до 14 ч.» с падежами), при этом «ст. 5
  ч. 2» — по-прежнему «статья пять, часть вторая»; «согласно ст. 5» —
  «согласно статье пять» (дательный падеж); «пос. Иванова, пер.
  Слесарный, лит. А» — «посёлок, переулок, литера»; «Московской обл.» —
  «Московской области» (согласование с прилагательным); «и/или» —
  слитно, без паузы.
- **Даты и техника без хвостов**: «от 21.01.2025 г.» — без двойного
  «года» (и «от 12.03.2021 года» тоже), при этом «2021 г. Москва»
  понимает «г.» как город; «с 2020 по 2024 год» — «с две тысячи
  двадцатого по две тысячи двадцать четвёртый год» (оба конца
  порядковые); «не более 3 лет» — «не более трёх лет» (родительный
  после сравнительной степени); «Т-34», «Су-27», «ФЗ-152» — дефис
  обозначения не звучит паузой; «18+» — «восемнадцать плюс».
- **Ритм перечислений**: однородные члены («документы, справки,
  выписки и квитанции») звучат с подъёмом тона на каждом элементе и
  спокойным завершением на последнем — как живой чтец ведёт список.
  Придаточные («он пришёл, чтобы…») и деепричастные обороты — без
  искусственного подъёма. Однородность определяется по синтаксическому
  дереву (rel=conj), а не по падежным тегам, которые у неоднозначных
  форм («документы/справки/выписки») размечены непредсказуемо.
- **Падежные конструкции**: «в течение 10 дней» — «в течение десяти
  дней», «по истечении 30 суток» — «тридцати суток», «в рамках 3
  программ» — «трёх программ»; «в силу ст. 61» — «в силу статьи»,
  «в порядке ст. 131» — «в порядке статьи».
- **«Ли»-вопросы**: «Подтверждаете **ли** вы…» — подъём тона на
  смысловом слове перед «ли» (как в живой речи), а не на последнем
  слове фразы. Обычные полярные вопросы по-прежнему поднимаются в
  конце.
- **Омографы-омонимы**: «замок на воротах» — замо́к, «феодальный
  замок» — за́мок; «пшеничная мука» / «мешок муки» — мукá и муки́,
  «муки ожидания» — му́ки (строгий дефолт + контекстные правила).
- **Скорость**: модель ударений грузится один раз на весь запуск
  (проба голоса + разметка + озвучка + пакет папки) — тесты ускорились
  в пять раз, повторные конвейеры стартуют мгновенно.
- **КАПС-усиление**: слово, набранное заглавными в судебном акте
  («суд УКАЗАЛ…»), выделяется голосом — замедление и подъём тона,
  как живой чтец подчёркивает слово.
- **Без повторов**: «100 000 (сто тысяч) рублей» — расшифровка в скобках
  не читается дважды; «т.н. льгота» — «так называемая льгота»
  (согласование по роду); «В 158-160 статьях» — «в ста пятидесяти восьми
  — ста шестидесяти статьях» (падеж по предлогу).
- **ID3-теги**: готовые MP3 содержат название, автора и год — плеер
  покажет «Лектор · Лекция о договоре», а не безымянный файл.
- **Аббревиатуры**: первая «УК РФ» читается полностью («Уголовный кодекс
  Российской Федерации, далее — УК РФ»), дальше — кратко. «149-ФЗ» →
  «сто сорок девять фэ-зэ». Неизвестные — по буквам.
- **Чистка**: колонтитулы, номера страниц, лишние дефисы переносов убираются;
  сноски — пропускаться или читать в конце потише (настройка).

## Пользовательские словари (по желанию)

Папка **`словари`** рядом с программой:

- **`ударения.txt`** — свои ударения, по одному слову в строке, ударная
  гласная помечается плюсом: `остр+ота`, `м+ука`, `твор+ог`. Словарь живёт
  до перезапуска программы — правьте файл и нажмите «Озвучить» снова.
- **`замены.txt`** — замены произношения: `эстоппель = эстопп+эль`.

Программа работает и без них — всё выше делается автоматически.

## SSML (для тонкой настройки, необязательно)

В тексте можно использовать:

- `<break time="500ms"/>` — пауза 0,5 секунды;
- `<emphasis>слово</emphasis>` — логическое ударение на слово;
- `<prosody rate="slow">фрагмент</prosody>` — медленнее (`fast` — быстрее).

## Отчёт

Рядом с аудио сохраняется `имя.отчёт.txt`:

```
== Запятые (2) ==
1. Запятая проигнорирована как пауза
```

## Командная строка

```
.venv\Scripts\python.exe -m lektor лекция.txt              # -> Аудиолекции\*.mp3
.venv\Scripts\python.exe -m lektor закон.pdf -o закон.mp3 --voice baya
.venv\Scripts\python.exe -m lektor текст.txt --markup      # только разметка и отчёт
.venv\Scripts\python.exe -m lektor --list-voices           # список голосов
.venv\Scripts\python.exe -m lektor --version               # версия программы
.venv\Scripts\python.exe -m lektor --doctor                # самодиагностика
```

## Требования

- Windows 11 (на 10 тоже работает), 8 ГБ памяти достаточно.
- Видеокарта не обязательна: Silero отлично работает на процессоре
  (~1–2 минуты аудио в минуту). С NVIDIA (6–12 ГБ) доступен HD-голос
  Chatterbox — медленнее собирается, зато живее.
- Диск: ~2 ГБ (CPU-вариант) или ~5 ГБ (с Chatterbox).

## Известные ограничения (честно)

- Замедление сложных фрагментов работает только на Silero; Chatterbox
  игнорирует `rate="slow"` (паузы между синтагмами сохраняются).
- Chatterbox без NVIDIA (то есть на AMD) работает на процессоре и очень
  медленный: час аудио собирается часами. Для длинных текстов берите Silero.
- Голос Chatterbox при клонировании повторяет образец, но не копирует
  его в точности.
- Если голос вдруг звучит «безударной кашей» — значит, не завёлся
  silero-stress; переустановите его:
  `.venv\Scripts\python.exe -m pip install --force-reinstall silero-stress`

## Состав и лицензии

Техническая заметка: файлы `.bat` сохранены в кодировке DOS (CP866) с
переводами строк CRLF — так их гарантированно понимает cmd.exe. Не
пересохраняйте их в UTF-8, иначе установщик сломается.
